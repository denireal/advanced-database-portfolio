## 2. Database Tables
The intended database design includes:
1. departments
2. programmes
3. students
4. lecturers
5. courses
6. academic_sessions
7. semesters
8. course_offerings
9. course_registrations
10. results
11. users
12. audit_logs

The final table list and definitions will be verified against the implemented database.

## 3. Implementation Procedure
1. Create and verify the database.
2. Implement the tables and their relationships.
3. Apply constraints and integrity rules.
4. Insert suitable sample records.
5. Execute verification queries.
6. Capture screenshots of the implementation.

## 4. Evidence
Screenshots and implementation notes will be stored in the `screenshots/` and `documentation/` directories.
